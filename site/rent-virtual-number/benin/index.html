Why did my OTP not arrive on the Benin virtual number?

OTPs may fail if the app's SMS gateway does not support Benin carriers at that moment, or if the app previously flagged the number. Try requesting the code again, or use the voice call option. If the code never arrives, you're covered by an automatic refund.

What's the difference between a temporary number and a rental number?

A temporary number is used once for a single code and then expires. A rental number stays active for a period (1 day to 1 month), allowing you to receive multiple codes over time. Choose rental if you need ongoing access to your account.

What should I NOT use a virtual number for?

Do not use virtual numbers for 2FA in banking, government identity verification, or any service that requires long-term, SIM-based authentication. These services often detect virtual numbers and may lock your account.

Can I use a Benin virtual number on WhatsApp if I already have a WhatsApp account?

Yes, but you will need to use a secondary account or WhatsApp Business. WhatsApp does not allow two accounts with the same number, so the virtual number must be a different number from your primary one.

How long does it take to receive an SMS on a Benin rental number?

Codes usually arrive in under 30 seconds, but it can take up to 60 seconds depending on the app's SMS delivery speed. If nothing appears in the dashboard after 60 seconds, try the voice call option or request a new code.

Will the rental number work if I log in from a different device later?

If you rented the number for a longer period (e.g., 7 days or 30 days), it should still be active on your dashboard. However, some apps require re-verification using the same number, which your rental will still be able to receive.
